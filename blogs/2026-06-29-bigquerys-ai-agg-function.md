BigQuery's new AI.AGG() function, now in preview, summarizes millions of rows using natural-language instructions inside SQL, supporting unstructured and multimodal data for use cases like log analysis, text categorization, and image analysis. It handles context window limits via multi-level aggregation and allows custom model endpoints for advanced workloads.
